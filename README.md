\# 🎓 EduVision Analytics



\## 🏢 О компании

\*\*EduVision Analytics\*\* — учебный проект, занимающийся анализом образовательных данных.  

Основная цель — выявить факторы, влияющие на академическую успеваемость студентов, с использованием инструментов SQL, Python и PostgreSQL.



---



\## 📊 Описание проекта

Проект основан на датасете \*\*StudentsPerformance.csv\*\*, содержащем информацию о:

\- поле студентов,

\- этнических группах,

\- уровне образования родителей,

\- типе школьного обеда,

\- участии в курсах подготовки,

\- результатах экзаменов по математике, чтению и письму.



---



\## ⚙️ Используемые инструменты

\- \*\*PostgreSQL\*\* — хранение данных  

\- \*\*Python (pandas, psycopg2, matplotlib, sqlalchemy)\*\* — анализ и визуализация  

\- \*\*dbdiagram.io\*\* — ER-диаграмма  

\- \*\*GitHub\*\* — публикация проекта
